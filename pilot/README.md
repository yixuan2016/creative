# ADS-WORK-05 试点执行模板

本目录提供将《企业运行认知基础设施试点实施方案——以项目交付为例》转化为实际启动材料的空白模板。

## 文件

- [试点章程模板](./试点章程模板.md)：明确发起人、样板项目、范围、目标、资源、风险和审批。
- [数据源与权威字段矩阵](./数据源与权威字段矩阵模板.csv)：逐字段确认来源系统、权威程度、数据分类、用途和审批。
- [基线与验收指标采集表](./基线与验收指标采集模板.csv)：记录基线、目标、样本、实际值和证据。
- [Agent 输出人工核验记录](./Agent输出人工核验记录模板.csv)：记录关键结论、来源、人工接受 / 修正 / 驳回和后续动作。
- [Agent 协同运行评估表](./Agent协同运行评估模板.csv)：记录 Run、Task、Agent、Context、委派、工具、审批、证据质量、人工修正和成本。

## 使用顺序

1. 先完成试点章程并明确责任人。
2. 再逐字段完成数据源与权威字段矩阵。
3. 在真实数据接入前完成授权与安全评审。
4. 采集基线并冻结指标口径。
5. Agent 进入影子运行和人工确认后，使用人工核验记录持续评测。

## 注意

CSV 中的 SRC-001 等示例仅用于说明填写方式，不代表任何真实企业系统、字段或授权已经确认。正式使用前应由系统责任人和业务责任人逐项核实。不得把示例阈值视为已批准验收标准。
