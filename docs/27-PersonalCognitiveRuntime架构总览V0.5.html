从事件账本到持续认知

Event Ledger过去 · 发生了什么

Source / Evidence / Observation / Event / Assertion。已确认事件保留历史与证据，不被记忆覆盖。

Memory Engine持续 · 哪些值得记住

偏好、原则、个人事实、决策、经验、技能和经历。具备证据引用、有效时间、版本修订和撤回。

State Engine当前 · 已知状态

当前重点、开放承诺、阻塞事项、下一步行动、长期记忆和近期事件。每次投影生成 as_of 快照。

Intent Engine未来 · 准备实现什么

目标、承诺、计划、里程碑、任务和愿景。新意图默认 proposed，只有用户显式激活后才是 active。

Personal Agent Runtime协作 · Agent 能看什么

多个 Agent 共享授权范围内的记忆、意图和个人状态，只读访问；每次请求重新校验用途、敏感度和来源有效性。

四个引擎的分工

Memory

把有长期价值的信息保存为可修订对象。

  • 类型化记忆
  • 证据支持关系
  • 版本与有效时间
  • 确认与撤回

State

把当前已知信息编译为时点快照。

  • 当前重点
  • 开放承诺
  • 阻塞和下一步
  • 不确定性与引用

Intent

把用户未来方向变成可治理生命周期。

  • 目标与承诺
  • 优先级和截止时间
  • 激活、阻塞、暂停、完成
  • 状态变更审计

Reflection

从已确认事件生成候选，不替用户下结论。

  • 决策 → 记忆候选
  • 学习 → 经验候选
  • 承诺 → 意图候选
  • 交付 → 经历候选

治理边界

已落实
  • Reflection 只生成待审核候选。
  • Intent 默认 proposed，用户激活后才进入 Agent 上下文。
  • 记忆修订保存旧版本和原因。
  • 来源失效会隐藏派生对象并要求复核。
  • Agent 只读并动态重新验证权限。
当前不做
  • 不自动推断人格、心理状态或绩效。
  • 不自动激活目标或创建外部任务。
  • 不主动发送消息或调用外部 Agent。
  • 不把个人记忆默认投影到企业域。
  • 本地撤权不能擦除外部 Agent 已复制的数据。
