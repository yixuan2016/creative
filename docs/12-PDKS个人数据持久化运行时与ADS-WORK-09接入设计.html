04 / SAFETY RULES

关键运行约束

  1. 每次写入使用原子事务和 owner revision；旧版本写入被拒绝并要求 refresh。
  2. Event ID 与 idempotency_key 防止重复写入。
  3. Agent 默认只能写入 candidate Memory / inferred_candidate Intent；确认态必须由 owner 明确操作。
  4. personal_sensitive 默认不进入上下文；候选记录默认不进入日常上下文。
  5. 来源撤回后派生 Memory 撤回，依赖来源的 Intent 暂停并要求 owner review。
  6. device_capture 与 connector_sync 必须经过可信授权引用验证。

重要：来源 suppression 不等于物理删除原始事件、录音文件和备份。

  --db ./data/personal-memory.sqlite3 --owner <owner-ref> \

  --db ./data/personal-memory.sqlite3 --owner <owner-ref> \
  --purpose personal_planning

授权引用必须来自可信授权解析器；模型不能自行编造授权引用。未经本人检查，不要将 active Memory 标记为 owner-confirmed。
