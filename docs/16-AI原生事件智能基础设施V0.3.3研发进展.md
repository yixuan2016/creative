# AI 原生事件智能基础设施 V0.3.3 研发进展

**版本：** V0.3.3 Alpha  
**定位：** PDKS / PALOS 个人数据运行时的来源生命周期治理验证  
**测试：** 76 项自动化测试通过；独立 ZIP 解压后复测通过

## 1. 本轮目标

V0.3.2 已建立本地只读 Connector Runtime、单机 Worker 和 PALOS Schema 只读预览。本轮补齐授权撤回之后的历史数据治理，避免系统只停止未来同步，却继续保留可被检索、投影或编入 Agent 上下文的历史派生数据。

## 2. 新增能力

- 来源删除影响预览；
- 显式 confirm=true 的不可逆 Source Purge；
- Evidence / Observation / Assertion / Participant 清理；
- PipelineRun / ModelInvocation 清理；
- 独占事件删除，跨来源支持事件保留；
- EventRelation、Review Queue、FTS 检索项清理；
- RDF 投影记录与本地文件失效；
- 受影响 State Snapshot 删除；
- 引用受影响事件的 Context Bundle 撤销；
- 内容寻址文件共享引用检查；
- 最小删除回执与审计；
- 事件详情 UI 增加“预览并删除此来源”。

## 3. 删除语义

来源独占支持的事件随来源删除；若仍有其他来源关联或证据支持，则保留事件本身，但移除当前来源的证据与断言，并使旧状态与上下文失效。内容哈希相同且被其他 Source 引用的原始文件不会被误删。

## 4. 验证

- 76 passed；
- Python compileall passed；
- OpenAPI 32 paths；
- 独立 ZIP fresh-extraction test：76 passed。

## 5. 未完成与边界

- 只清理 EIL 本地库和受控 raw/rdf 目录；
- 不清理操作系统备份、文件系统快照、用户导出副本；
- 不调用外部提供方删除接口；
- 不连接真实 PALOS 数据库；
- 不启用 DingTalk DWS CLI；
- 不支持多主机分布式 Worker；
- 不是法律合规认证或生产就绪声明。

下一阶段需要在真实 PALOS Schema 与官方 DWS CLI 资料基础上形成经过审核的 Adapter Profile。
