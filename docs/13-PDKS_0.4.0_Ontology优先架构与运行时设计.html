01 / PRINCIPLE

四个角色，不能混成一个系统

Ontology 定义数据意义；Schema 定义数据结构；Database 负责数据持久化；Agent 负责理解和使用数据。

本阶段不替换 SQLite，也不把 RDF 图谱作为唯一事实源。 Canonical JSON 是权威记录，RDF 是版本化、可重建的语义投影。

04 / SEMANTIC SAFETY

六组必须分开的概念

05 / STORAGE

SQLite 是权威存储，RDF 是可重建视图

表责任
