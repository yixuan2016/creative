03 / SHACL RUNTIME

从文件存在到图真的符合约束

新增 SHACL 运行时接口，覆盖 Owner 唯一性、敏感度和访问范围、事件 Taxonomy、Assertion 认知状态、Evidence 来源、个人上下文主体、设备采集授权引用、Agent Action 审批语义、跨 Owner 关系和 QualifiedRelationship 白名单。

SHACL 只能检查授权引用是否存在，不能证明授权真实有效。实际授权仍须由可信 Consent / Policy Service 执行。缺少 pySHACL 时返回 unavailable，不伪装为通过。
04 / VERSION COMPATIBILITY

历史版本不再悄悄失去语义身份

0.2.0 保留为历史版本；0.2.1 使用独立目录。旧版 26 个类、45 个属性全部建立等价桥接，34 个 SKOS 概念通过稳定 notation 与 exactMatch 映射。Record Schema 仍保持 0.1.x，不强制重写历史 JSON。
