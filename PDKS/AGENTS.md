# Instructions for Agents Working With This PDKS Bundle

Before installing, initializing, repairing, or connecting this bundle, read `skills/pdks-setup/SKILL.md` and its references.

- Run read-only `doctor` and `plan` first.
- Present the exact install path, dependencies, network access, and unencrypted-storage warning.
- Do not execute `install` until the user approves the exact plan hash and explicitly acknowledges the preview storage limitation.
- Installation does not imply DWS login, data collection, historical import, background service, cloud backup, or Agent directory changes.
- Do not run as administrator/root and do not overwrite existing user data.
- Report actual command outcomes. Do not claim local installation from a cloud-only sandbox.
- This release is experimental. Do not collect sensitive personal or enterprise data because Capture Runtime 0.1.1 does not encrypt data at rest.
