# PDKS Example Scenarios

Each scenario folder is self-contained and uses illustrative placeholder identities:

- `scenarios/voice-meeting/`: a voice-meeting capture spanning all nine PDKS object types.
- `scenarios/daily-work/`: work event, project context, assertion and action links.
- `scenarios/research/`: event-to-knowledge derivation, personal context and qualified relationship.

The sample owner and leader are placeholders, not real identities. The sample source locator and content hash are illustrative and do not point to an actual recording.
