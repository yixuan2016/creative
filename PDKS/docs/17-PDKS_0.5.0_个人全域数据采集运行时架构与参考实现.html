Capture pipeline

从原始材料到个人资产

01 · RECEIVE用户输入 / 文件上传先明确来源与数据领域
02 · AUTHORIZE身份与授权检查自动采集默认拒绝
03 · PRESERVE原件暂存与去重SHA-256、幂等键、原始来源
04 · EXTRACT抽取文本和证据片段保留定位与采集时间
05 · UNDERSTANDAgent 形成候选记录遵循 PDKS Ontology 与 Schema
06 · VALIDATE结构、来源、权限校验不符合就拒绝或待复核
07 · REVIEW用户确认、纠正候选不自动成为事实
08 · PRESERVE持久化、检索、导出记录可携带、可撤回

Privacy by default

默认保护规则

  • 自动采集默认拒绝；Connector / Device 需要匹配的 Consent Grant。
  • 默认 `owner_only`，当前原型不接受组织共享范围。
  • 每个 Agent 使用独立 Token 和最小权限。
  • 候选记录必须由用户确认，不把模型推断自动变成事实。
  • 撤销授权阻止未来采集；删除会清理本地来源和依赖内容。
  • 本地删除不等于删除历史备份、外部副本和 OS 快照。
Storage & ontology

数据库与本体如何协作

  • PDKS Ontology：定义对象、语义和关系。
  • JSON Schema：校验记录结构。
  • SQLite：当前本地原型的事务持久化。
  • 文件 Vault：保存原始来源字节。
  • RDF：可重建的语义图投影。
  • 向量索引：未来可选，只能作为派生检索索引。

本版本没有升级 PDKS 标准或 Ontology 版本。

Quick start

本地运行最小步骤

python -m venv .venv source .venv/bin/activate python -m pip install -r runtime/requirements.txt export PYTHONPATH=runtime python -m pdks_capture_runtime --db ./data/pdks.sqlite3 --vault ./data/vault init --owner urn:pdks:owner:me python -m pdks_capture_runtime --db ./data/pdks.sqlite3 --vault ./data/vault token-create --owner urn:pdks:owner:me --agent-id agent-a --scopes capture:read,capture:write,records:read,records:propose python -m pdks_capture_runtime --db ./data/pdks.sqlite3 --vault ./data/vault serve --host 127.0.0.1 --port 8765

Windows PowerShell 激活虚拟环境和设置 PYTHONPATH 的方式见《普通用户本地试用指南》。服务只监听本机，不要暴露到公网。
