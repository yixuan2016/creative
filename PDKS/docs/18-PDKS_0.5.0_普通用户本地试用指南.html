PDKS · 0.5.0 · LOCAL TRIAL

普通用户本地试用指南

按步骤启动个人采集运行时。无需理解 Ontology 或数据库字段，但需要按照说明完成一次本地安装。

安全提醒：当前是实验性本地原型，SQLite 和原始文件库未加密。请先使用非敏感测试材料，且不要暴露到公网。
01 · 安装环境

安装 Python 3.10+，在工程包根目录创建虚拟环境并安装本地 Runtime。

python -m venv .venv
# Windows PowerShell: .venv\\Scripts\\Activate.ps1
# macOS / Linux:
source .venv/bin/activate
python -m pip install -e runtime
02 · 初始化个人数据区

初始化一个本地 owner 分区。

pdks-runtime --db ./data/pdks.sqlite3 --vault ./data/vault init --owner urn:pdks:owner:me
03 · 为 Agent 创建独立 Token

每个 Agent 使用自己的 Token。Token 只显示一次，应放在宿主的 Secret Manager 中。

pdks-runtime --db ./data/pdks.sqlite3 --vault ./data/vault token-create --owner urn:pdks:owner:me --agent-id agent-a --scopes capture:read,capture:write,records:read,records:propose
04 · 启动本地服务

服务只监听 127.0.0.1。云端 Agent 无法直接访问用户电脑的本机地址。

pdks-runtime --db ./data/pdks.sqlite3 --vault ./data/vault serve --host 127.0.0.1 --port 8765
05 · 手工采集第一条记录

也可以直接用 CLI 做一次最小试用。

pdks-runtime --db ./data/pdks.sqlite3 --vault ./data/vault capture-text --owner urn:pdks:owner:me --domain work --text "今天开会讨论了项目计划。"

运行完整合成演示

在 runtime 目录运行 python examples/demo_local_flow.py，体验采集、候选记录、用户确认和导出校验。仅使用临时目录和合成会议材料。

当前支持的文件类型

材料当前处理
TXT / MD / CSV / JSON可提取文本
HTML / EML / ICS可提取可见正文或部分字段
DOCX可提取正文段落
PDF / 图片 / 音频 / 视频保留原件，等待专用提取器
XLSX / PPTX保留原件，暂未实现深度提取

请记住

  • 钉钉、微信等原生连接器尚未实现，当前可以先由用户导出后上传。
  • 麦克风、录音卡、定位和桌面活动未实现，默认关闭。
  • Agent 生成的是候选记录，必须由用户确认。
  • 撤销授权只阻止未来采集；删除历史备份和外部副本需要单独处理。
  • 不要把 Token 写进 Skill 文件、聊天记录或 GitHub。

详细架构见《PDKS 0.5.0 个人全域数据采集运行时架构与参考实现》。
