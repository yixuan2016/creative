Non-negotiable principles

本轮研发的六条硬约束

01 · 不夸大能力文档定义不等于集成完成，原型存在不等于生产可用。
02 · 冻结稳定基线Ontology 0.2.1、Schema 0.1.x、Taxonomy 0.1.0 本轮不升级。
03 · 数据最小化个人原始录音、私人对话和个人上下文默认不向组织共享。
04 · 宿主授权优先连接器、持久化和自动化必须依赖真实工具和明确授权。
05 · 证据与推断分离保留来源、证据、置信度和用户确认状态。
06 · 研究提案不进正式标准个人/企业/中心扩展仅作为 proposal，不新增正式术语。
Next-stage exit criteria

什么时候才能进入个人数智底座原型阶段？

  1. 至少两个宿主 Agent 环境完成安装、调用和一致性验证。
  2. 真实工作场景中的来源、证据、时间和不确定性可追溯。
  3. 重复导入、纠错、撤回、删除和导出有可重复测试。
  4. 连接器权限、持久化回执和授权撤回路径明确。
  5. 完成真实试点数据的隐私与质量评估。
  6. 用户能够理解、修正和撤销 Agent 生成的个人上下文。

这些是未来阶段退出条件，不代表 0.4.2 已经全部达成。
