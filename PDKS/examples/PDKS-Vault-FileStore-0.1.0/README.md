# PDKS Vault

This is a portable, file-first PDKS knowledge vault. It can be opened directly in Obsidian.

- Markdown + YAML Frontmatter: human-readable knowledge assets.
- JSON / JSONL: source records and evidence.
- `assets/sha256/`: original attachments addressed by content hash.
- `.pdks/index/`: rebuildable index; safe to recreate from files.

PDKS does not require Obsidian. Do not sync this folder to a cloud provider unless you have explicitly reviewed and approved that provider and data scope.
