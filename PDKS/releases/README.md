# PDKS Releases

Release archives and manifests belong here. Each release must include:
- version and development stage;
- compatibility baseline (Schema, Taxonomy, Ontology);
- per-file SHA-256 manifest;
- test summary and explicit skipped tests;
- unexecuted integration checks;
- migration and rollback notes;
- security limitations.

0.5.3 is an experimental transition-stage preview, not production-ready.
