# PDKS Development Stage

- Release: 0.5.3 preview
- Stage: `transitional_skill_development`
- Maturity: experimental, not production-ready
- Current focus: Node-native Bootstrap, Agent interoperability, File-first Vault initialization
- Ontology baseline: 0.2.1 frozen
- Data collection by default: disabled
- Cloud sync by default: disabled
- Encryption at rest: not implemented

PDKS is a transitional engineering track toward a future Personal AI Life OS. Do not describe this release as a completed Personal AI Life OS or production-ready personal data platform.
