# PDKS Cross-Agent Benchmark 0.1.0

This benchmark is part of the transitional Skill development track. It is not a production certification.

- `prompts/`: agent-facing prompts only; do not expose evaluator labels.
- `cases/`: evaluator-side acceptance criteria and critical failures.
- `benchmark-manifest.json`: version and run requirements.
- `CROSS_AGENT_TEST_PROTOCOL.md`: host setup and execution process.
- `BENCHMARK_RUNNER_GUIDE.md`: prompt isolation and run handling.
- `OUTPUT_CONTRACT.md`: candidate result JSON envelope.
- `EVALUATION_RUBRIC.md`: human scoring rubric.
- `run-results-template.csv`: 72 planned run slots.
- `review-scorecard-template.csv`: per-run human scorecard.

Status: 12 synthetic cases and protocol prepared; actual cross-host runs have not been executed.
