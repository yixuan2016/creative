# 过渡阶段 Skill 开发定位与能力边界

> 状态：研发约束文件（0.4.2） · 成熟度：Experimental / Preview

## 当前定位

PDKS 当前处于过渡阶段的 Skill 开发。目标是验证一套可被 Agent 调用、可跨宿主迁移、能够把日常信息组织为个人工作上下文和知识资产的指令、数据契约与参考工具。

当前交付物是 Skill 工程和参考原型，不是完整的个人数智底座产品，不是企业级数据平台，也不是已经完成的 ADS 集成。

## 能力状态

| 状态 | 含义 |
|---|---|
| available_in_skill | Skill 指令已定义，Agent 可处理用户主动提供的材料 |
| prototype_local | 本地参考代码可运行，依赖本地环境与操作者 |
| prototype_partial | 部分流程或接口存在，端到端能力未完成 |
| host_dependent | 依赖宿主 Agent 工具、连接器、权限和运行环境 |
| not_implemented | 当前未实现 |
| future_research | 未来研究方向 |

禁止把“文档中定义了接口”表述成“已经完成集成”；禁止把“生成了文件”表述成“已经保存到目标系统”；禁止把“有 SQLite 原型”表述成“已有云端个人记忆服务”。

## 本轮包含

- 从用户主动提供的文本、文件和转录材料中识别事件、行动、断言、知识、关系与个人上下文。
- 将候选记录映射到 PDKS 0.1.x 记录模型和 Ontology 0.2.1。
- 保留来源、证据、时间、置信度、敏感级别、访问范围与授权引用。
- 在宿主能力允许时调用本地脚本做结构校验、SQLite 原型持久化、RDF 投影和导出。

## 本轮不包含

- 后台持续录音、自动监听、设备固件或原生录音卡连接。
- 未经确认的钉钉、邮件、日历或企业系统连接。
- 生产级身份认证、密钥管理、端到端加密、跨设备同步或正式 Consent / Policy Service。
- 自动把个人数据写入企业或中心数据空间。
- 将个人、企业、中心 Ontology 关系作为已发布的继承标准。

## Skill 与平台的关系

Skill 是 Agent 的可移植行为规范和资源包；宿主 Agent 提供模型、工具、连接器、文件访问、持久化、授权与执行环境；外部服务提供真实身份、策略和业务系统能力。

安装 Skill 不会自动获得连接器或数据权限。没有持久化回执时，只能说“已整理/已生成”，不能说“已保存”。没有可信授权服务时，不能把 consent_ref 当作真实授权证明。

## 阶段退出条件

1. 至少两个宿主 Agent 环境完成安装、调用和结果一致性验证。
2. 典型工作场景有来源追溯。
3. 重复导入、纠错、撤回、删除和导出边界可验证。
4. 每一种连接器、持久化和自动化能力的授权与执行回执明确。
5. 有可重复的质量测试与隐私测试。
6. 用户能够理解、修正和撤销 Agent 生成的个人上下文。

以上是未来退出标准，不代表当前版本已经达成。
