## 研究主线

本仓库的连续研究主线是：

**多源工作感知 → 个人工作记忆 → 授权与语义映射 → 企业数智资产 → 企业工作上下文 → 企业运行认知 → 企业端口智能体协同与持续改进。**

其中，个人数智底座负责个人工作信息的自主沉淀；企业数智底座融合企业既有业务系统、知识和经授权的协同信息，并形成标准业务数据、运行上下文和能力资产；业务领域中心数智底座通过共同语义、联邦资产目录、授权协调和跨域治理提供支撑。工作上下文基础设施是企业数智底座内部的能力体系，不是新增的第四级底座，也不是员工持续监控系统。

## 架构基线

- ADS-12：三级数智底座矩阵架构，V0.3。
- ADS-19：三级数智底座统一数据模型与资产目录，V0.4。
- ARCH-ADS-001：AI Native 数智基础设施总体架构，V1.0-Review。

## 研究边界

本仓库中的研究文件属于架构研究与方案讨论，不等同于已批准的生产部署规格、法律意见或工程实现。涉及个人信息、员工工作记录、第三方信息和企业数据的采集、处理与共享，须另行通过组织制度、安全和适用法律审查。
